# TAID 데모 검수 시나리오

이 문서는 API 키 없이 발표용 프로토타입을 3분 안에 검수하는 절차입니다. 모든 샘플 결과에는 `SAMPLE` 또는 `DEMO` 표시가 보여야 합니다.

## 시나리오 A — 지식 카드 전체 흐름

1. `/` 홈페이지에서 `MVP 체험하기`를 눌러 `/app`으로 이동합니다.
2. `설비 QR 데모`를 누릅니다.
3. 작업지시 `WO-260818-042`, 품목 `A모델`, 설비 `AS-02`를 포함한 한 묶음의 작업 맥락이 채워졌는지 확인합니다.
4. 다음 단계에서 `AI 없이 한 번의 회고 샘플 체험`을 누릅니다.
5. 구조화 결과 상단에 `SAMPLE · AI 미사용`이 표시되는지 확인합니다.
6. 작업지시·품목·공정·설비가 이전 단계와 같은지 확인합니다.
7. 필수값과 수량을 확인하고 작업자 확인 체크 후 `검토 요청으로 저장`을 누릅니다.
8. 완료 화면과 승인함에서 같은 카드와 `SAMPLE` 표시를 확인합니다.
9. 승인함에서 카드를 승인합니다. 승인한 카드는 다시 반려할 수 없어야 합니다.
10. 승인 지식 검색으로 이동해 해당 카드가 나타나는지 확인합니다.
11. 코치 답변에 `RULE DEMO · RAG 아님`이 표시되는지 확인합니다.

## 시나리오 B — 한 번의 3분 회고 직접 입력

1. 새 기록을 시작하고 작업 맥락을 선택합니다.
2. 세 질문이 `말하기 가이드 · 답변란 아님`으로 한 화면에 함께 보이는지 확인합니다.
3. 질문별 입력란이나 이전·다음 단계 없이 `3분 회고 전체 전사문` 한 곳에 내용을 입력합니다.
4. 녹음을 멈췄다가 다시 시작하면 기존 전사문 뒤에 새 내용이 이어지고, 기존 내용이 유지되는지 확인합니다.
5. 전체 회고의 녹음 제한이 3분이며 현재 누적 시간이 모바일에서도 보이는지 확인합니다.
6. `전체 회고를 AI로 정리`가 전체 전사문을 한 번만 구조화하는 동작인지 확인합니다.
7. 브라우저 음성 인식이 없거나 권한을 거부해도 같은 전사문 입력란에서 텍스트로 계속 진행할 수 있는지 확인합니다.

선택형 AI를 설정하지 않은 환경에서 `전체 회고를 AI로 정리`를 누르면 실제 AI 결과로 넘어가면 안 됩니다. 오류가 표시되고 사용자가 샘플 전환을 선택할 수 있어야 합니다.

## 시나리오 C — 오늘 전체 특이사항 없음

1. 작업 맥락을 선택하고 `오늘 전체 특이사항 없음`을 누릅니다.
2. `참여 완료` 화면이 나타나는지 확인합니다.
3. 관리자 승인함과 지식 검색에 새 카드가 생기지 않았는지 확인합니다.
4. 대시보드의 이번 주 회고에 참여 완료가 반영되는지 확인합니다.
5. 같은 데모 기간·참여자·작업지시로 다시 완료해도 건수가 중복 증가하지 않는지 확인합니다.

## 시나리오 D — 저장·초기화·모바일

1. 카드를 저장한 후 브라우저를 새로고침해 카드와 승인 상태가 유지되는지 확인합니다.
2. 360~390px 폭에서 맥락 선택부터 승인 지식 확인까지 버튼이 가려지지 않고 완료되는지 확인합니다.
3. 작성 중 화면을 나가거나 초기화하려 할 때 손실 확인 안내가 나타나는지 확인합니다.
4. `데모 초기화` 후 카드, 승인 상태, 검색어, 코치 질문·답변, 회고 전사문, 참여 완료가 초기 상태로 돌아가는지 확인합니다.

## 합격 기준

- 로그인, DB, API 키 없이 시나리오 A와 C를 끝까지 완료할 수 있습니다.
- 샘플 데이터가 어느 화면에서도 `LIVE AI`로 표시되지 않습니다.
- 승인된 카드만 지식 검색에 나타납니다.
- 세 질문은 각각의 필수 답변란이 아니라 한 번의 회고를 돕는 안내 가이드로 동작합니다.
- 새 기록과 데모 초기화 후 이전 작성 내용이 새 회고에 섞이지 않습니다.
