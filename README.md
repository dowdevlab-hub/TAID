# TAID Voice + Knowledge MVP

작업자의 짧은 음성 회고를 구조화하고, 중요값 확인과 관리자 승인을 거쳐 재사용 가능한 현장 지식으로 전환하는 인터랙티브 MVP입니다.

## 포함된 흐름

- `/`: TAID 제품 홈페이지
- `/app`: 작업자·관리자 통합 MVP 워크스페이스
- 공정·설비 선택 또는 QR 스캔 데모
- 한국어 브라우저 음성 인식과 텍스트 대체 입력
- 품목·수량 등 중요값 재확인
- 검토 대기 → 승인/보완 요청
- 승인 지식 검색과 근거 부족 응답
- 파일럿 지표·반복 이슈 대시보드
- 브라우저 로컬 저장을 이용한 데모 상태 보존

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
npm test
```

## MVP 경계

현재 버전은 제품 가설을 검증하기 위한 프런트엔드 MVP이며 샘플 데이터를 사용합니다. 실제 운영 전에는 서버 저장소, 조직별 데이터 격리, 역할 기반 권한, STT/LLM 작업 큐, 원음 보관·삭제 정책, 감사 로그, 실제 공장 음성 정확도 평가가 필요합니다.
