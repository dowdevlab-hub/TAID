# TAID 데모 프로토타입

TAID는 제조 현장의 짧은 회고를 문제·개선·노하우 카드로 정리해 보는 **발표·사용성 검증용 DEMO PROTOTYPE**입니다.

> 현재 버전은 `SAMPLE` 흐름을 기준으로 합니다. 로그인, 공용 데이터베이스, API 키, 별도 환경변수 없이 홈페이지부터 승인 지식 검색까지 체험할 수 있습니다.

## 현재 범위

| 제공하는 것 | 아직 제공하지 않는 것 |
| --- | --- |
| 홈페이지와 모바일 대응 체험 화면 | 실제 운영용 로그인·권한 관리 |
| 작업지시·품목·공정·설비 선택 | 공용 DB와 여러 사용자 간 동기화 |
| 한 번의 3분 회고와 세 가지 말하기 가이드 | 실제 생산 KPI·MES·ERP 연동 |
| 브라우저 음성 인식과 텍스트 입력 | 실제 RAG·ML 패턴 분석 |
| 샘플 구조화·확인·저장·승인·검색 | 운영 수준의 감사 로그·보안 통제 |
| `특이사항 없음` 참여 완료 | 현장 성과나 ROI의 검증된 수치 |

화면의 `DEMO`, `SAMPLE`, `RULE DEMO · RAG 아님` 표시는 합성 데이터와 규칙 기반 동작임을 뜻합니다. 선택형 AI 기능이 성공한 결과만 `LIVE AI`로 표시됩니다.

## 화면

- `/` — TAID 소개 홈페이지
- `/app` — 작업자 회고, 관리자 승인함, 승인 지식 검색을 연결한 체험 화면
- `/api/structure` — 선택형 AI 구조화 엔드포인트. 샘플 데모 실행에는 필요하지 않습니다.

## 빠른 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시된 로컬 주소로 접속한 뒤 `/app`을 여세요. 일반적인 주소는 `http://localhost:3000/app`입니다.

환경변수는 설정하지 않아도 됩니다. 첫 체험은 다음 순서가 가장 빠릅니다.

1. `설비 QR 데모`를 눌러 작업 맥락을 채웁니다.
2. `AI 없이 한 번의 회고 샘플 체험`을 선택합니다.
3. 구조화 결과를 확인하고 검토 요청으로 저장합니다.
4. 승인함에서 승인한 뒤 승인 지식 검색에서 확인합니다.

상세 검수 절차는 [데모 검수 시나리오](docs/DEMO_SCENARIO.md)에 있습니다.

## 검증

```bash
npm run lint
npm test
```

`npm test`는 배포용 빌드 후 자동 테스트를 실행합니다.

## 데이터 저장 방식

카드와 참여 완료 기록은 서버가 아니라 현재 브라우저의 `localStorage`에만 저장됩니다.

- `taid-mvp-cards-v2` — 샘플 또는 선택형 AI 구조화 카드와 승인 상태
- `taid-mvp-no-issue-checkins-v1` — `특이사항 없음` 참여 완료 기록

따라서 다른 브라우저·기기로 데이터가 전달되지 않으며, 브라우저 데이터를 지우면 기록도 사라집니다. 화면의 `데모 초기화`로 초기 상태를 복구할 수 있습니다.

## 선택형 AI 기능

소스에는 한 번의 3분 회고 전체 전사문을 한 번에 구조화하는 `POST /api/structure` 구현이 포함되어 있습니다. 화면의 세 질문은 각각 별도로 답하거나 녹음하는 입력란이 아니라, 자연스럽게 말하도록 돕는 안내 가이드입니다. 이 기능은 현재 발표용 샘플 데모의 필수 조건이 아닙니다. 설정하지 않으면 화면에서 오류를 명확히 알리고 사용자가 `SAMPLE` 흐름을 선택해 계속할 수 있습니다.

선택형 기능을 별도로 시험할 때만 `.env.example`을 참고하세요. 비밀값은 Git에 커밋하지 마세요.

## 인수와 배포

- GitHub 저장소가 소스 코드의 기준입니다.
- `.openai/hosting.json`은 현재 ChatGPT Sites 프로젝트의 연결 정보이며 비밀키가 아닙니다.
- GitHub 소유권과 기존 Sites 주소·공개 범위·프로젝트 권한은 서로 별개입니다. 저장소를 넘겨도 기존 Sites 프로젝트 소유권은 자동으로 이전되지 않습니다.
- 이 코드는 이후 Vercel 등 다른 호스팅으로 이전할 수 있습니다. Supabase를 붙일 경우 인증·공용 DB 부분을 새로 연결하면 됩니다.

자세한 구조, 인수 범위, 알려진 한계는 [인수인계 문서](docs/HANDOFF.md)를 확인하세요.

## 저장소에서 제외한 것

원본 발표자료(PPT/PDF/DOCX 등), 분석용 원천 파일, 로컬 `.env`, API 비밀값, 브라우저 `localStorage`, 빌드 결과물은 이 저장소에 포함하지 않습니다.
